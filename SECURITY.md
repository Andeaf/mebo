# Security policy

This repository contains the source of a live production website. If you find
a vulnerability, please do not open a public issue.

Use GitHub's private vulnerability reporting instead: open the **Security** tab
of this repository and choose **Report a vulnerability**. Include the affected
route or component, steps to reproduce and the impact you expect.

Reports are acknowledged as soon as possible and fixed in the production
deployment before any details are published.

Only the `main` branch, as deployed to production, is supported.
