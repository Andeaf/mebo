# Projectfoto's — wat moet hier komen

**Let op:** de huidige foto's zijn VOORLOPIG en komen van het Instagram-profiel
(@mebo.keukens), max. ±1440 px breed. Voor de livegang vervangen door de
originelen — Instagram comprimeert flink en de hero heeft minimaal 2000 px
nodig. Vervang ze **met exact dezelfde bestandsnaam** — er hoeft dan niets in
de code te veranderen.

| Bestandsnaam | Wat er op moet staan | Minimale resolutie |
| --- | --- | --- |
| `hero-keuken-eiken.jpg` | Beste keukenproject, breed beeld (liggend). Dit is het eerste wat bezoekers zien. Donkere/sfeervolle foto werkt het best (er staat witte tekst overheen). | **2000 px breed** (liefst 2400×1600) |
| `ontwerp-showroom.jpg` | Ontwerpgesprek of showroom met stalen op tafel (staand beeld). Witte tekst onderin het beeld. | 1200×1500 |
| `productie-cnc.jpg` | Productie/CNC-machine of werkplaats (staand beeld). Witte tekst onderin het beeld. | 1200×1500 |
| `montage-team.jpg` | Montage bij klant thuis (staand beeld). Witte tekst onderin het beeld. | 1200×1500 |
| `project-keuken-zwart-01.jpg` | Afgerond project, breed beeld. Er staat witte tekst in het midden — kies een rustige, donkere foto. | 2400×1350 |
| `materialen-eiken-fronten.jpg` | Materialen/stalen: houtfronten, kleuren (liggend beeld). Geen tekst overheen. | 1600×1200 |
| `proces-tekening-montage.jpg` | Tekening, opmeten of montage-detail (liggend beeld). Geen tekst overheen. | 1600×1200 |
| `maatwerk-werkplaats.jpg` | Werkplaats of sterk detailshot, breed beeld. Er staat grote witte tekst overheen — donkere foto verplicht. | 2400×1350 |

Ook in `/public`: `og.jpg` (1200×630) — de afbeelding die verschijnt als de
site gedeeld wordt via WhatsApp/social. Mag vervangen worden door een echte
projectfoto met logo.

Tips:

- JPG, kwaliteit ±80%. De site maakt er zelf AVIF/WebP-versies van.
- Foto's met warme belichting en hout passen het best bij de stijl van de site.
- Placeholders opnieuw genereren kan met `npm run placeholders`.
